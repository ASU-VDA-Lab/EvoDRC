**V2.W.1 — Width check**

**V2.S.1 — Projection-based spacing**

V2.S.1 constructs a per-instance mask whose shape depends on the M3 end-cap class, then runs projection spacing checks on the resulting mask edges:

- **nec (no end-cap):** All V2 edges are coincident with M3 edges. The mask extends 5 nm beyond each M3-coincident end.
- **wec (with end-cap):** At least one V2 edge is not coincident with M3. The mask adds a 5 nm lateral extension on the non-flush sides.

Effective projection thresholds: 18 nm for via pairs on the same M3 track or on aligned parallel tracks; 27 nm for non-aligned parallel M3 tracks. Trial:i01.ug.whole_design.00 included x-direction instance translations (i0012 +136 dbu, i0103 −28 dbu) on layers that include V2 and was gated in, demonstrating that inter-instance translation is a viable path for correcting projection spacing violations.

**V2.S.2 — Euclidean corner-to-corner spacing (both instances wec)**

V2.S.2 applies when both V2 instances belong to the wec class. It checks the Euclidean distance between the wec masks (each mask already includes the 5 nm end-cap extension) against a threshold of 16.4 nm, which corresponds to a 23 nm corner clearance in the physical layout. Trial:i01.ug.whole_design.00 performed x- and y-direction translations on V2-touching instances and was accepted, showing that translation-based separation is effective for this class.

**V2.S.3 — Euclidean corner-to-corner spacing (both instances nec)**

V2.S.3 applies when both V2 instances are nec-class. It checks the Euclidean distance between nec masks against 16.12 nm (30 nm effective after mask extension), but only for corner violations not already captured by the projection check — violations intersecting the projection result are excluded.
