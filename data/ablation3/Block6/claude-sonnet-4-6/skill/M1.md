## Repair Strategy: Coordinated M1 Reshape with Instance Moves

Five repair patterns appear across accepted trials on this layer.

**Pattern A — Polygon move with fan-out instance moves (trial:i04.ug.whole_design.00):** A single `move` op on an M1 polygon (p1684, axis: x, delta: +80 dbu) was paired with nine `move_instance` ops at the same magnitude (+80 dbu in x). This one-to-many relationship — one M1 polygon repositioned, many instances moved by the identical delta — produced zero new violations inside or outside the crop region with connectivity preserved (trial:i04.ug.whole_design.00). The instance set (i0025, i0040, i0108, i0126, i0409, i0412, i0530, i0031, i0538) confirms that a single M1 adjustment can require moving all instances whose vias interact with that polygon.

**Pattern B — Small symmetric resize with paired instance moves (trial:i04.ug.whole_design.00):** Three `resize` ops (not `resize_end`) on M1 polygons p1990, p1923, and p1920, each with axis: x and delta: 10 dbu, were each immediately followed by a single `move_instance` op. Instance displacements for these pairs were +96 dbu (i0319, i0213) and −96 dbu (i0074). The small resize magnitude (10 dbu) is op-type-distinct from `resize_end` deltas recorded in other iterations; both op types were accepted without new violations (trial:i04.ug.whole_design.00).

**Pattern D — One-to-one instance-then-polygon moves at equal delta (trial:i05.ug.whole_design.00):** Sixteen pairs each consisting of a `move_instance` followed immediately by a `move` on a single polygon, with equal x-axis displacement, were accepted with zero new violations. Deltas used: +13 dbu (6 pairs: i0446/p2072, i0093/p1903, i0410/p2020, i0239/p1946, i0536/p2071, i0361/p2086, i0404/p2019), +37 dbu (9 pairs: i0459/p2050, i0122/p1911, i0481/p2049, i0078/p1914, i0071/p1907, i0159/p2046, i0138/p1927, i0060/p1910, i0324/p2067, i0512/p2030), +48 dbu (1 pair: i0437/p2047). **Pattern E — Mismatched polygon and instance displacement (trial:i05.ug.whole_design.00):** One accepted pair moved polygon p1999 by −72 dbu and instance i0066 by −161 dbu on the x-axis. **Pattern C — Stand-alone instance moves (trial:i04.ug.whole_design.00, trial:i05.ug.whole_design.00):** Instance moves with no immediately paired M1 polygon op are present in both accepted trials.
