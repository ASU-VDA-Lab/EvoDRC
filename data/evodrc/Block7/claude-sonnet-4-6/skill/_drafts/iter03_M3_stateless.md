**Do not partially reverse a completed M3 spacing fix.**

In trial:i02.ug.leaf_0001.07, polygon p3383 in unit leaf_0001 was moved y=−57 dbu together with instance i1643, clearing all violations in the crop (n_new_in_crop=0). In trial:i03.ug.leaf_0001.03, the same polygon and instance were moved y=+21 dbu, partially reversing the prior correction. The full −57 dbu displacement was clean; the intermediate −36 dbu position was not. When an M3 polygon move has already cleared a spacing-class violation (M3.S.1 through M3.S.6), moving the polygon back toward its original position risks re-entering the violating gap. Commit the full corrective displacement and do not apply a subsequent opposing delta to the same polygon within the same repair sequence.

**New M3 polygons must have both edge spans > 36 nm to avoid tip-spacing rules.**

In trial:i03.ug.leaf_0002.04, an M3 polygon was added with corners at [11664,11756] and [11908,11828], giving an x-span of 244 dbu and a y-span of 72 dbu. When adding a new M3 polygon, keep both dimensions strictly above 36 nm to stay entirely within the side-edge regime and avoid activating the more restrictive tip-spacing checks.

**Multi-layer moves involving M3 and V2 require synchronized translation deltas to maintain via enclosure.**

Trials that touch M3 and V2 together in the same operation always translate the M3 polygon and the V2-bearing cell instance by identical delta vectors. In trial:i02.ug.leaf_0001.07, polygon p3383 and instance i1643 both moved y=−57 dbu, yielding 0 new violations. In trial:i03.ug.leaf_0001.03, the same polygon and instance both moved y=+21 dbu; though new violations appeared (n_new_in_crop=3), the synchronized delta itself is the required pattern — the violations arose from the net position, not from a delta mismatch. V2.M3.EN.2 requires ≥5 nm enclosure on two opposite sides; V2.M3.AUX.2 requires that V2 width exactly equals M3 width perpendicular to the M3 length direction. Synchronized translation preserves both enclosure overlap and the perpendicular width match by keeping the M3 envelope and via footprint in the same relative positions throughout the move.
