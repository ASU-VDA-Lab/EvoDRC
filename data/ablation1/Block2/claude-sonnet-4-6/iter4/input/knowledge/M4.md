  def offgrid_cl(axis, pitch_dbu, offset_dbu, base_dbu = nil)
    new_data = RBA::Region::new
    self.data.each do |p|
      bb = p.bbox
      if base_dbu
        if axis == :y
          next if bb.bottom % base_dbu != 0 || bb.top % base_dbu != 0
        else
          next if bb.left % base_dbu != 0 || bb.right % base_dbu != 0
        end
      end
      cl = axis == :y ? (bb.bottom + bb.top) / 2 : (bb.left + bb.right) / 2
      if (cl - offset_dbu) % pitch_dbu != 0
        if axis == :y
          new_data.insert(p.moved(0, cl - bb.bottom))
        else
          new_data.insert(p.moved(cl - bb.left, 0))
        end
      end
    end
    DRC::DRCLayer::new(@engine, new_data)
  end

  def ongrid_ep(gx_dbu, gy_dbu)
    result = RBA::EdgePairs::new
    self.data.each do |poly|
      pts = poly.each_point_hull.to_a
      pts.each_with_index do |pt, idx|
        offgrid_x = (gx_dbu > 1) && (pt.x % gx_dbu != 0)
        offgrid_y = (gy_dbu > 1) && (pt.y % gy_dbu != 0)
        if offgrid_x || offgrid_y
          pp = pts[(idx - 1) % pts.size]
          np = pts[(idx + 1) % pts.size]
          e1 = RBA::Edge::new(pp, pt)
          e2 = RBA::Edge::new(pt, np)
          result.insert(RBA::EdgePair::new(e1, e2))
        end
      end
    end
    DRC::DRCLayer::new(@engine, result)
  end

**Width constraints (vertical / y-axis).** M4.W.1 sets the minimum vertical width at 24 nm. M4.W.2 caps it at 480 nm. M4.W.4 adds a separate prohibition on widths 72, 168, 264, 360, and 456 nm (those that would span an even number of minimum-width routing tracks). M4.W.5 sets the minimum horizontal width at 44 nm.

**Spacing constraints.** M4.S.1 requires 24 nm minimum vertical spacing (projection and euclidian). M4.S.2 requires 40 nm minimum horizontal spacing between vertical edges. M4.S.3 and M4.S.4 both require 40 nm tip-to-tip spacing on adjacent tracks, covering both the no-shared-run-length and shared-run-length cases. M4.S.5 requires a minimum parallel run length of 44 nm between M4 polygons on adjacent tracks.

**Grid and topology constraints.** M4.AUX.1 requires all M4 horizontal edges to sit on a 24 nm grid. M4.AUX.2 constrains minimum-width M4 tracks to horizontal routing tracks with pitch 192 dbu and offset 48 dbu from the origin (base 96 dbu). M4.AUX.3 forbids any bend in M4 (no 0-90-degree interior corners). M4.AUX.4 forbids the outer horizontal edge of any wide M4 polygon from touching a routing track edge.

**Via enclosure.** V3.M4.EN.2 requires M4 to enclose V3 by at least 11 nm on two opposite sides. V3.M4.AUX.2 requires V3 to be exactly the same width as M4 in the direction perpendicular to the M4 run. V4.M4.EN.1 requires M4 to enclose V4 by at least 11 nm on two opposite sides.
