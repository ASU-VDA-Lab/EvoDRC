  def offgrid_cl(axis, pitch_dbu, offset_dbu, base_dbu = nil)
    new_data = RBA::Region::new
    self.data.each do |p|
      bb = p.bbox
      if base_dbu
        if axis == :y
          next if bb.bottom % base_dbu != 0 || bb.top % base_dbu != 0
        else
          next if bb.left % base_dbu != 0 || bb.right % base_dbu != 0
        end
      end
      cl = axis == :y ? (bb.bottom + bb.top) / 2 : (bb.left + bb.right) / 2
      if (cl - offset_dbu) % pitch_dbu != 0
        if axis == :y
          new_data.insert(p.moved(0, cl - bb.bottom))
        else
          new_data.insert(p.moved(cl - bb.left, 0))
        end
      end
    end
    DRC::DRCLayer::new(@engine, new_data)
  end

  def ongrid_ep(gx_dbu, gy_dbu)
    result = RBA::EdgePairs::new
    self.data.each do |poly|
      pts = poly.each_point_hull.to_a
      pts.each_with_index do |pt, idx|
        offgrid_x = (gx_dbu > 1) && (pt.x % gx_dbu != 0)
        offgrid_y = (gy_dbu > 1) && (pt.y % gy_dbu != 0)
        if offgrid_x || offgrid_y
          pp = pts[(idx - 1) % pts.size]
          np = pts[(idx + 1) % pts.size]
          e1 = RBA::Edge::new(pp, pt)
          e2 = RBA::Edge::new(pt, np)
          result.insert(RBA::EdgePair::new(e1, e2))
        end
      end
    end
    DRC::DRCLayer::new(@engine, result)
  end

## Rejected Operations and Root-Cause Patterns

**Multi-polygon M4 moves that improve one unit window while worsening an adjacent window will be rejected even when the per-window delta appears small.**
Trial trial:i03.cu.def:VIA_VIA45_1_2_58_58.00 moved two M4 polygons (`p1143` by +32 dbu, `p1142` by -16 dbu) along the x-axis as part of a four-operation group that also resized via shapes in M5. The `unit:leaf_0007` window improved by -2 violations, but `unit:leaf_0008` worsened by +18, yielding a net `delta_total` of +16. The trial was rejected with decision `rejected_net_positive`. Do not accept a repair group whose aggregate violation delta across all affected windows is positive, even when local improvement is visible in a subset of windows.

**Asymmetric moves across grouped M4 polygons propagate enclosure and spacing violations laterally.**
In trial trial:i03.cu.def:VIA_VIA45_1_2_58_58.00 the two M4 polygons were moved by different amounts (+32 and -16 dbu), and the accompanying via shape resizes targeted M5 only. The net-positive outcome indicates that the differential displacement of `p1143` relative to `p1142` shifted enclosure margins (V3.M4.EN.2, V4.M4.EN.1) or horizontal spacing margins (M4.S.2) into violation in the `leaf_0008` window. When moving multiple M4 polygons as a group, prefer uniform displacement to avoid creating relative-position violations between adjacent conductors.
