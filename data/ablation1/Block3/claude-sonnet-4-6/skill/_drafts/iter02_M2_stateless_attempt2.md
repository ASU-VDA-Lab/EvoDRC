## DRC rule summary

M2 minimum width is 18 nm (M2.W.1). Side-to-side spacing between edges longer than 36 nm is 18 nm (M2.S.1). Tip-to-side spacing — one edge <= 36 nm, the other > 36 nm — is 25 nm (M2.S.2). Tip-to-tip spacing when both edges are 24–36 nm is 27 nm (M2.S.3); when one edge is 24–36 nm and the other is < 24 nm, 31 nm (M2.S.5); when both edges are < 24 nm, 31 nm (M2.S.4). Corner-to-corner euclidian spacing is 20 nm (M2.S.6). Minimum area is 504 nm² (M2.A.1). Rule M2.S.7 forbids an 18 nm tip-to-tip gap co-located with side-to-side spacing <= 32 nm; parallel run length must be >= 35 nm in that configuration. Rule M2.S.8 enforces a minimum 80 nm diagonal center-to-center distance between tip-to-tip gaps on different tracks. V1 enclosure by M2 requires 5 nm on two opposite sides (V1.M2.EN.2), and V1 must match M2 width in the direction perpendicular to M2 length (V1.M2.AUX.2). V2 enclosure by M2 requires 5 nm on at least two opposite sides (V2.M2.EN.1). Non-orthogonal edges are forbidden on all drawing layers including M2 (GEOMETRY.NONORTHOGONAL).

## Paired resize_end when a polygon endpoint must track a moved instance

When a move_instance operation displaces geometry such that an M2 polygon endpoint must remain flush with the moved boundary, a matching resize_end operation on that endpoint is required for the trial to be accepted. In trial:i01.ug.leaf_0008.06, a resize_end on polygon p1261 (axis x, end high, delta_dbu 36) accompanied two move_instance ops each of 36 dbu, and the trial was gated_in with conn_preserved. In trial:i02.ug.leaf_0001.00, a resize_end on the same polygon p1261 (axis x, end high, delta_dbu 72) accompanied a move_instance on i0047 of 72 dbu, and the trial was again gated_in with conn_preserved. Do not omit the resize_end when an M2 polygon endpoint must track a moved instance on the x-axis (trial:i01.ug.leaf_0008.06, trial:i02.ug.leaf_0001.00). The resize_end delta must equal the move_instance delta on the same axis, as confirmed across both recorded instances of this pattern.
